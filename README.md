# Apprentissage du C

Ce dépôt retrace mon apprentissage du langage C grâce à un suivis de petits cours vidéos : notes, code, exercices et mini-projets.

## Notes et Apprentissage

Ce fichier : **[apprentissagec](https://github.com/WireLess-00/apprentissage-c-/tree/main/apprentissagec)** contient des notes,du code et des exercices sur les bases du C mais aussi sur des notions plus poussées comme les pointeurs, les tableaux, les chaines de caractères, structures...
