
GitHub :

Clone repositories :
- git clone "SSH link from github"

Commit :
- git add "name.c"
- git commit -m "message"

Push to git :
- git push

Update : 
- git pull

To ignore files :
Create a .gitignore file and list the files to ignore

Conflicts :
- git push --rebase

++ :
- git log
- cd .. :go back
- cd ~ : home
- git status
