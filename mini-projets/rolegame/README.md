# Role Game

Mini RPG jouable en console : création de personnage, choix narratifs, puis combat au tour par tour contre un ennemi.

## Fonctionnement

1. **Création du personnage** : choix du genre, puis saisie d'un pseudo caractère par caractère (3 à 8 caractères)
2. **Choix du rôle** : le joueur choisit une classe parmi Ghost, Alien, Possessed ou Medium
3. **Combat au tour par tour** : à chaque round, le joueur choisit une compétence (attaque, soin, ou double attaque) ; l'ennemi riposte automatiquement

## Améliorations 

- L'ennemi inflige toujours les mêmes dégâts
- Limite les pseudos à 8 caractères
- Pas d'égalité si les deux personnages tombent à 0 PV le même round
